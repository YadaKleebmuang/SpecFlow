# Locked Holdout Test Set Notice

> [!IMPORTANT]
> ชุดข้อมูลทดสอบใน `app/rasa/tests/nlu_test.yml` ถูกล็อก (Locked / Frozen) ตามระเบียบวิธีประเมินผล NLU ของโปรเจกต์ SpecFlow 
> 
> **ข้อห้ามสำคัญ**:
> 1. ห้ามนำตัวอย่างประโยคใน `nlu_test.yml` ไปใส่กลับในชุดข้อมูลฝึก (`nlu.yml`)
> 2. ห้ามปรับแก้ตัวอย่างประโยคทดสอบเพื่อทำให้โมเดลได้คะแนนสูงขึ้น
> 3. หากพบว่าโมเดลทำนายผิดพลาดในชุดทดสอบนี้ ให้ดำเนินการปรับแก้เฉพาะข้อมูลฝึก (`nlu.yml`) หรือปรับแต่ง NLU Pipeline (`config.yml`) เท่านั้น
