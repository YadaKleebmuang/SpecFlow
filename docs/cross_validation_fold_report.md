## 5. บทวิเคราะห์ความเสถียรของแต่ละ Fold (Fold Stability Analysis)

จากการวิเคราะห์ผลการประเมิน 5-Fold Cross-Validation พบว่า Fold ที่มีประสิทธิภาพ Accuracy สูงสุดคือ **Fold 5 (86.05%)** ในขณะที่ Fold ที่มี Accuracy ต่ำสุดคือ **Fold 1 (76.36%)** ส่งผลให้มีช่วงคะแนน (Range) ต่างกัน 9.69% โดยตัวชี้วัดที่มีค่าความเบี่ยงเบนมาตรฐาน (SD) สูงที่สุดในภาพรวมคือ Entity Recall (SD = 0.0631) และ Intent Precision (SD = 0.0466) ตามลำดับ

สาเหตุหลักของความผันผวนมาจาก Intent สนทนาขนาดเล็ก เช่น `affirm` (Support = 7, F1 SD = 0.3249) และ `deny` (Support = 8, F1 SD = 0.4183) ซึ่งในแต่ละ Validation Fold จะมีจำนวนตัวอย่างเพียง 1-2 ข้อความ หากโมเดลใน Fold นั้นๆ สับสนคำตอบ จะทำให้ค่า F1-Score ของ Intent ดังกล่าวตกเป็น 0.0000 ทันที ในทางกลับกัน Intent หลักอย่าง `build_pc` (F1 Mean = 0.9264, SD = 0.0776) และ `upgrade_pc` (F1 Mean = 0.8636, SD = 0.2083) มีความเสถียรและให้ประสิทธิภาพการจดจำประโยคคำขอจัดสเปกคอมพิวเตอร์ในระดับสูง

สำหรับด้านการดึง Entity เอนทิตี `budget` (F1 Mean = 0.8472, SD = 0.0973) และ `usage` (F1 Mean = 0.7861, SD = 0.0806) มีเสถียรภาพสูงเนื่องจากมีตัวอย่างการกำกับข้อมูล (Support) ที่หนาแน่น ในขณะที่ `future_upgrade` มีค่า SD สูงสุด (SD = 0.2216) เนื่องจากขอบเขตความยาวของวลีที่ผู้ใช้พิมพ์บอกความต้องการเผื่ออัปเกรดมีความหลากหลายสูง
